glo·sshlittlessh · glotui

An SSH console for microcontrollers. ssh admin@<board> and you're on the device: a config shell, a status screen, or a full ANSI-art BBS.

SSH 2.0 Engineered for Bounded Silicon

Most embedded devices rely on unencrypted Telnet or bloated multi-megabyte ports. glossh pairs littlessh (a minimal callback-driven SSH 2.0 server built on PSA Crypto with strict zero-heap execution) and glotui (a differential 16-color ANSI-art terminal UI that sends only changed cell buffers) on hardware as lean as an ESP32-S3 with W5500 Ethernet.

02 · glotui: differential ansi-art engine

glotui renders CP437 glyphs and colors into a two-dimensional virtual cell buffer. Rather than blasting full-screen ANSI redraws across the network, gt_flush() diffs the current buffer against the previous frame and streams only changed cells.

04 · cryptographic suite & guarantees

Component Specification Guarantees & Memory Safety
Key Exchange curve25519-sha256 Strict KEX enforcement (kex-strict-s-v00@openssh.com). Ephemeral keys scrubbed immediately.
Host Key ecdsa-sha2-nistp256 32-byte P-256 scalar generated once and pinned in NVS. Fingerprint printed at boot.
Symmetric Cipher aes256-gcm@openssh.com Authenticated encryption with AEAD integrity verification.
User Auth Password & Publickey 60-second authentication timeout prevents unauthenticated clients from hoarding slot.
Heap Allocation Zero Heap after Start All channel windows, packet buffers, and session states allocated prior to accept().

05 · quickstart guide

Desktop Host Test (Linux / macOS)

sudo apt install build-essential libmbedtls-dev openssh-client
cd test/host && make bbs_host
./bbs_host 2323
ssh -p 2323 caller@127.0.0.1        # password: bbs

Flash to LilyGO T-ETH-ELITE S3 (ESP32-S3 + Ethernet)

cd examples/esp32_bbs
idf.py set-target esp32s3
idf.py build flash monitor
# Then from your workstation:
ssh -t admin@<board-ip>            # password: changeme
